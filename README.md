# Hallenbuch Heinrich-Böll-Schule

Digitales Hallenbuch für die drei Sporthallen (Alte Halle, Neue Dreifeldhalle, Tischtennishalle):
Übergabe-Check beim Trainingsbeginn, Mängelmeldung mit Fotos, Zuordnung zur Belegungszeit, Kontakte, Belegungsplan.

Stand: Prototyp (Testversion). Alle Vereine, Ansprechpartner und der Belegungsplan sind fiktiv.
Einträge bleiben in dieser Version nur auf dem jeweiligen Gerät. Eine gemeinsame Version mit
Datenbank und Fotospeicher ist der nächste Schritt.

Die App ist eine einzelne Datei: `index.html`.
