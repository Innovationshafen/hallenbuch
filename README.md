# Hallenbuch Heinrich-Böll-Schule

Digitales Hallenbuch für die drei Sporthallen von HBS und LOG (Alte Halle, Neue Dreifeldhalle, Tischtennishalle):
Mängelmeldung mit Fotos, freiwillige Bestätigung "Alles in Ordnung" mit einem Tipp, Zuordnung zu den Belegungen
laut Plan samt Zeitfenster seit der letzten Bestätigung, Kontakte, Belegungsplan für Schulen und Vereine
mit parallelen Belegungen und Hallenteilen.

Stand: Prototyp (Testversion). Alle Vereine, Schulen, Ansprechpartner und der Belegungsplan sind fiktiv.
Einträge bleiben in dieser Version nur auf dem jeweiligen Gerät. Eine gemeinsame Version mit
Datenbank und Fotospeicher ist der nächste Schritt.

Die App ist eine einzelne Datei: `index.html`.
